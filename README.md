# Flappy Bob 🟡

Un gioco arcade ispirato a Flappy Bird, realizzato con **Pygame**.

## 🎮 Caratteristiche

- **Menù principale** con pulsanti interattivi
- **Gameplay fluido** a 60 FPS
- **Sistema di punteggio** in tempo reale
- **Istruzioni in-game** integrate
- **Effetti visivi** e colori vivaci

## 📋 Requisiti

- Python 3.7+
- Pygame

## ⬇️ Installazione

1. ** Scarica**
2. [Flappy Bob](https://github.com/saffdds/FlappyBob/releases/download/FrappyBobv1.0.0/bob.exe)
